## Fixed

- **Extensions can't take Medusa's reserved keys anywhere.** An extension shortcut set to a key Medusa keeps for itself, like ⌘Q, ⌘N or ⌘W (or wherever you rebound them), could still win in a detached DevTools window, a picture-in-picture window, or as a Global shortcut. Medusa's command runs now in all of them, and a Global shortcut on one of those keys isn't registered. Every other extension shortcut works as before, Global ones included.
